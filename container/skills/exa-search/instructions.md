The official Exa Search skill (`exa-search`) is installed. Use it for semantic web search via `POST https://api.exa.ai/search`. `EXA_API_KEY` holds only a non-secret marker; the credential gateway injects the real `x-api-key` header for api.exa.ai on behalf of authorized agents. Send requests exactly as the skill shows. Do not ask for, store, or print an Exa API key, and do not install the SDK just to search.
