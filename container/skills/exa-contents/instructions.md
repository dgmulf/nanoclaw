The official Exa Contents skill (`exa-contents`) is installed. Use it to extract text, highlights, or summaries from URLs you already have via `POST https://api.exa.ai/contents`; use `exa-search` when you need to find pages first. `EXA_API_KEY` holds only a non-secret marker; the credential gateway injects the real `x-api-key` header for api.exa.ai on behalf of authorized agents. Send requests exactly as the skill shows. Do not ask for, store, or print an Exa API key.
